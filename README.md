# 洋流 — 垃圾袋飄帶練習室

Three.js 網頁遊戲。選垃圾袋 → 看教學 → 穿帶、控力、折耳、繞圈、平衡 → 整理與評分。

## 執行

需 Python 3。在本資料夾執行：

    python -m http.server 5173 --directory dist

瀏覽器開啟 http://localhost:5173 。請透過 HTTP 伺服器執行，不能直接雙擊 index.html 載入模組。

## 核心操作

1. 交叉穿帶：按順序穿過三個節點。
2. 控力收緊：保持 65–82% 拉力 0.8 秒後放開；拉力超過 102% 持續 0.25 秒會滑脫。
3. 折出左耳：沿弧線穿過四個節點，不能只拖終點。
4. 繞圈穿結：繞過五個節點，再從左下穿出。
5. 雙耳平衡：兩耳各拉至 82–110%，差距低於 13% 才能收結。滑鼠可以逐耳操作，觸控可用雙指。

支援方向鍵穿帶、控力與平衡，Enter 放手；也提供獨立的輔助完成按鈕。每一步輔助以 55% 手感計分，紀錄會另作標示。

自由練習不限時。手感挑戰有 90 秒倒數、FLOW 連段和滑脫計數；逾時可重試或轉自由練習繼續完成。開啟說明或切換分頁時暫停。

最後可整理左右垂帶、張力，旋轉欣賞、下載 PNG 作品。環境音預設關閉。最佳紀錄保存在本機，依模式與是否使用輔助分開。

## 透明袋

透明版本裝有程序化 3D 提袋、帽子、徽章及吊飾。使用者提供的圖示已透過內建 imagegen 製作強模糊版，所有小物只使用模糊後的 PNG。原始清晰圖示不隨本專案散布。處理記錄與完整提示詞見 ASSET-NOTES.md。

## 評分

穿帶手感 40、雙耳平衡 20、垂帶整理 20、收結張力 20。穿帶路徑、過度繞行、滑脫、穩定拉力與雙耳差距都會影響分數。50 cm 左右的垂帶與約 72% 結心張力是整理目標。

## 原始碼

- dist/app.js：場景、袋身與飄帶曲面、互動、模式、評分與匯出。
- dist/gesture-engine.js：有序穿點、拉力停留、雙耳平衡判定。
- dist/merchandise.js：袋內競選小物。
- dist/assets/merch-mark-blurred.png：模糊小物圖示。
- dist/assets/ribbon.png：使用者提供的飄帶紋理。
- dist/assets/three.module.js：Three.js 0.170.0，授權見 THREE-LICENSE.txt。

線上版：https://lou12331.github.io/taipei-current-ribbon/ 。推到 main 時，GitHub Actions 會先跑下方檢查，再把 dist/ 發布到 GitHub Pages。

`python build-artifact.py artifact-build` 會把 dist/ 打包成單頁版本，供 claude.ai Artifact 發布使用（CSS、JS 內嵌，Three.js 改從 jsDelivr 載入）。

執行檢查：

    node check-gameplay.mjs
    node check-bag.mjs
    node --check dist/app.js

採用有步驟約束的幾何變形，並非完整布料物理求解。主要資源已隨專案附上；Google Fonts 無網路時改用系統字體。搜尋的洋流視覺來源收在頁面「靈感筆記」。本作為非官方創作。

## 透明垃圾袋・章東西更新

選項名稱為「透明垃圾袋」，副標精確使用「章東西」。袋內垃圾沿袋壁 360° 環狀堆放：提袋、帽子、徽章、吊飾、杯子、傳單與揉皺紙團、寶特瓶、鋁罐、紙箱混合，每件都朝外並依袋面曲率推到貼近塑膠袋，正面、側面與背面都看得到；袋心以 InstancedMesh 小包裝填實。

飄帶改為彈簧驅動的連續動畫：每條帶子固定數個控制點，朝當前步驟的姿態彈性收斂，切換步驟、拖曳、重試都會平順變形；耳朵沿穿點路徑長出再收成蝴蝶結，垂帶尾端剪成燕尾並隨風輕擺。教學預覽依時間連續播放五個步驟。
